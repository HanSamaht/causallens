
## ABSOLUTE RULE: ENGLISH ONLY

ALL files in this repository must contain ZERO Chinese characters.
This includes: code, comments, docstrings, variable names, string literals,
test assertions, README, documentation, configuration files, concept packs.
No exceptions. No Chinese punctuation either (，。：；！？「」『』（）【】).
Before any commit, run: `python -c "..."` to verify zero Chinese.
If any Chinese is found, the commit is BLOCKED.

## Writing style rules

- No exclamation marks
- No dramatic language ("This is not X — this is Y", "One hidden assumption did Z", "The AI refused to overclaim")
- No rhetorical questions
- No emotional appeals ("looks ready for production", "breaking the law")
- No unnecessary bold text
- State facts plainly: subject, verb, object, number
- Let numbers speak. Do not interpret them for the reader.
- Remove all filler words: "genuinely", "fundamentally", "essentially", "completely", "truly"
- One sentence says one thing. No compound dramatic reveals.
- If a claim needs "—" to connect two ideas dramatically, split into two sentences.
- Write like a technical report, not a blog post.
- No em dashes or en dashes in any written output. Use colons, commas, or periods instead.
